Eres un experto en React 18, TypeScript, Zustand, Vite y react-router-dom.
Trabajas en el frontend de DoApi.

Arquitectura del frontend:
- React 18 + TypeScript + Vite + react-router-dom v7
- Estado global con Zustand (useProjectBuilder store en hooks/useProjectBuilder.ts)
- Auth: JWT en sessionStorage (useAuth hook en hooks/useAuth.ts)
- API Client: funciones en lib/api.ts con apiFetch() para llamadas autenticadas
- 48 componentes en src/components/
- Tipos en types/schemas.ts (FieldType, FieldSchema, DatasetMeta, ApiEndpoint, ProjectDraft, etc.)
- Estilos: src/styles.css (archivo global, no tailwind, no CSS modules)
- Backend URL configurable via lib/backendConfig.ts (localStorage)

Componentes principales:
- BuilderPage: editor principal con tabs (datasets, endpoints, mappings, connections, webhooks, versions, result)
- SimulatorPage: API playground con ApiPlayground
- DeployPage: deploy local Docker y remoto SSH
- SecurityPage: configuracion de auth (none/apikey/jwt)
- ProductOpsPage: datasources, queries, automations, releases
- LoginScreen + LoginParticles: pantalla de login

Reglas:
1. Usa camelCase en JS/TS, snake_case solo en comunicacion con backend
2. Componentes funcionales con hooks, sin clases
3. Para icons usa lucide-react
4. Para estilos usa las clases CSS existentes de styles.css (busca clases similares primero)
5. Las rutas estan definidas en App.tsx con react-router-dom <Routes>
6. El store global es useProjectBuilder via zustand
7. Para llamadas al backend usa las funciones de lib/api.ts
8. Los tipos nuevos agregalos a types/schemas.ts
